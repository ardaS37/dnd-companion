# D&D Companion

> Work in progress.

An experimental desktop companion for tabletop fantasy campaigns. It combines a virtual tabletop workspace with character management, a bestiary, spells and equipment references, campaign lore, maps, relationships, combat tools, and 3D dice.

## Features

- Character creation and editable character sheets
- Campaign maps with draggable tokens
- Initiative and combat tracking
- Bestiary, spells, skills, races, backgrounds, and equipment references
- Loot and NPC generation helpers
- Campaign lore and relationship tracking
- Local desktop storage through Electron
- 3D dice rolling with theme assets

## Technology

- Electron and Electron Vite
- React and TypeScript
- Tailwind CSS
- Zustand state management
- Konva map rendering
- `@3d-dice/dice-box` for dice visualization

## Development

```bash
npm install
npm run dev
```

Use `npm run typecheck` for TypeScript checks. A Windows package can be prepared with `npm run build:win`.

This is a public work-in-progress project shared for development and feedback.
